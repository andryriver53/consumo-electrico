# Proyecto de Algorítmica - Control de Consumo Eléctrico Residencial

Este es un sistema interactivo desarrollado en Python para auditar y calcular el consumo eléctrico estimado en hogares residenciales, aplicando factores de potencia estándar y tarifas vigentes del país.

## 💻 Características del Sistema
* Cálculo de consumo en kilovatios-hora (kWh) usando el factor de potencia residencial ($cos(\phi) = 0.85$).
* Validación de datos de entrada para evitar errores del usuario (voltajes, amperajes y horas de uso válidas).
* Procesamiento modular mediante funciones independientes para el cálculo y la facturación.
* Menú dinámico para el registro continuo de múltiples electrodomésticos.
